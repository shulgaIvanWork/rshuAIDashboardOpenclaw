# 📊 Bitrix24 Dashboard — дашборд продаж 2026

Node.js сервер и интерактивный дашборд для анализа продаж из Битрикс24.

## Быстрый старт

```bash
npm install
npm start        # production
npm run dev      # разработка с авто-перезапуском (nodemon)
```

Сервер запускается на порту **3001**.

## API endpoints

| Endpoint | Описание |
|----------|----------|
| `GET /api/kpi` | KPI-карточки: выручка, средний чек, конверсия, лучшая неделя, дельта |
| `GET /api/weekly` | Агрегация по ISO-неделям 2026 года |
| `GET /api/top-managers` | Топ-20 менеджеров по сумме выигранных сделок |
| `GET /api/deals` | Все 13 000+ сделок (сырые данные) |
| `GET /api/dicts` | Справочники: воронки, стадии, источники, пользователи |
| `GET /api/status` | Статус загрузки: ready/loading/error |
| `POST /api/refresh` | Принудительная перезагрузка сделок из Битрикс24 |

## Дашборд

Интерактивный дашборд (`/`):
- **6 KPI-карточек**: выручка, средний чек, конверсия, воронка, лучшая неделя, текущая неделя
- **3 графика**: выручка по неделям (bar), количество сделок (stacked bar), средний чек (line)
- **Таблица детализации** по неделям: создано, выиграно, проиграно, конверсия
- **Топ-20 менеджеров**: рейтинг по сумме продаж
- **Кнопка «Экспорт в Excel»** — скачивает таблицу в XLSX (SheetJS)
- **Кнопка «Обновить данные»** — перезапрашивает сделки из Битрикс24
- Graceful loading: пока данные грузятся — спиннер, после — дашборд

## Технологии

- **Сервер**: Node.js (ESM), Express
- **Графики**: Chart.js 4.x (CDN)
- **Экспорт**: SheetJS (CDN)
- **Данные**: Битрикс24 REST API (вебхук), кеш на диск

## Источник данных

Битрикс24: `https://24.uprav.ru/rest/479/a98jbqufylu1si1e/`

При первом запуске сервер выгружает ~13 000 сделок за 2026 год и кеширует их. Последующие запуски — мгновенные из кеша. Для обновления данных — кнопка на дашборде или `POST /api/refresh`.
