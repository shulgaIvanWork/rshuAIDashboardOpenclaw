## Фильтры данных

**Оплаченные сделки (основные):**
- CATEGORY_ID=0 (Sale)
- OPPORTUNITY > 0
- UF_DATE_PAY_1C в периоде
- STAGE_SEMANTIC_ID=S (WON)

**Артефакты (выводить отдельно с *):**
- STAGE_SEMANTIC_ID=P + UF_DATE_PAY_1C → частичная оплата/рассрочка
- STAGE_SEMANTIC_ID=F + UF_DATE_PAY_1C → возврат клиенту

**Исключаются всегда:**
- Копии (TITLE содержит "копия"/"copy")
- Технические оплаты (WON + OPPORTUNITY=0)

**Создано в периоде:**
- Sale (cat=0): все (S+F+P)
- PreSale (cat=8): P + F (без WON — копии)
