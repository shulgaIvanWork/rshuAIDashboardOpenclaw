### 🔑 Новая бизнес-логика (утверждено с Ольгой)

**Поступления (правило):**
- Только `UF_DATE_PAY_1C` (дата оплаты из 1С) + WON + сумма > 0
- Возвраты: UF_DATE_PAY_1C + LOSE + >0 — считаем, показываем отдельно
- Артефакты (P + UF_DATE_PAY_1C) — пишем Ольге на проверку
- Без даты (WON без UF_DATE_PAY_1C) — не считаем
- Технические (сумма = 0) — не считаем нигде

**Срок WON:** от `DATE_CREATE` до `UF_DATE_PAY_1C` (не CLOSEDATE)

**Лиды = кол-во созданных сделок** в PreSale + Sale + КОМ (не crm.lead).

**Деление ООМ/КОМ (5 признаков):**
- Галочка `UF_CRM_1683882427069` = Y
- Формат `UF_FORMAT` = «КОМ» (19042498)
- Направление `UF_CRM_1498466811` = «Корпоративное обучение» (1906)
- Категория = 19 «КОМ Sale»
- Тип обучения `UF_CRM_1765896709800` = «КОМ» (34765)

**KPI — 3 строки × 7 карточек:** Общая (ООМ+КОМ), ООМ, КОМ
1. Поступления YTD
2. Лиды YTD
3. Конверсия YTD
4. Средний чек YTD
5. Срок WON (дн.)
6. Текущая неделя: поступления (с датами 01.06—06.06)
7. Текущая неделя: лиды

**Воронка (5 этапов):**
1. Лиды — созданы PreSale+Sale+КОМ (без тех.)
2. MQL — PreSale → в Sale от MQL и далее + КОМ Sale
3. SQL — из КОМ Sale + Sale от SQL и далее
4. Счёт отправлен — стадии PROPOSAL+ и UF_CRM_1753272713011
5. Оплачено — UF_DATE_PAY_1C + WON + >0

**Стадии Sale:**
- MQL+: MQL, SQL, Счёт отправлен, Постоплата, Частично оплачен, Счёт оплачен, Закрыто, Предзакрытие в отказ, Приоритет, Следующий год
- SQL+: SQL, Счёт отправлен, Постоплата, Частично оплачен, Счёт оплачен, Закрыто, Предзакрытие в отказ

**B2B/B2C:** только по наличию COMPANY_ID (не по сумме/категории)

**Форматы:** ООМ, ОМ, СДО, КОМ. MMBA(3), Вечерний(3), ГК(3) — артефакты.

**Типы обучения (круг+таблица):** Краткосрочное, Повышение квалификации, Проф.переподготовка, КОМ

**MBA/MMBA подтипы:** Классический, Эксперт, Специализация, Микро
