## Дашборд рейтингов
### Источники — полная переработка
- Новый `src_funnel` — рассчёт по логике управленческого дашборда (без КОМ)
- Воронка: Лиды→MQL→SQL→Счёт→Сделка с конверсиями на каждом этапе
- Столбцы: Источник | Лиды | MQL | SQL | Счёт | Сделки | Поступл. | Ср.чек | Цикл | Лиды→MQL | MQL→SQL | SQL→Счёт | Счёт→Сделка | Лид→Сделка | Тип трафика
- Тип трафика: ВНБ (синий #1f2a44) / МТ (бирюзовый #00bcd4), в ИТОГО — текст "Внутренняя база / Маркет. трафик"
- Строки: ИТОГО (топ-20) → топ-20 источников → Остальные (N) → ИТОГО (все без КОМ)
- Цвета итогов: #fff8e1 (жёлтый), остальные: #f0f4ff (голубой)
- Фильтр по датам пересчитывает `src_funnel` из недельных `by_src` (добавлены leads, mql, sql, invoice_cnt в by_src)
- Цикл в by_src — DC→PAY_DT (было DC→CL)
