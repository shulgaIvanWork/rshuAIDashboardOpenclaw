## 📐 Логика расчётов (утверждено 09.06.2026)

### VALID_CATS
Только категории 0 (Sale), 8 (PreSale), 19 (КОМ Sale).
Все остальные (9 PostSale, 10 Аккаунтинг, 12 Отказы, 13 RepeatSale, 20 Реанимация) — исключены везде.

### MIN_OPP = 11.0 ₽
Минимальная сумма сделки для учёта. Сделки с суммой 0–10 ₽ не считаются.

### Поступления (карточка 1)
```
Поступления = сумма OPPORTUNITY где:
  UF_DATE_PAY_1C IS NOT NULL     # дата оплаты из 1С
  AND OPPORTUNITY >= 11 ₽        # MIN_OPP
  AND CATEGORY_ID IN (0, 8, 19)  # только валидные категории
  (SEM не проверяем — считаем любые стадии с оплатой)
```
Возвраты (SEM=F + оплата) считаются в общую сумму, но выводятся в артефактах.

### Лиды (карточка 2)
```
is_all_lead:
  CAT_ID IN (0, 8, 19)           # только валидные
  И НЕ (SEM=S AND OPP < 11)      # не тех.нулевые WON
  И НЕ (CAT_ID IN (8,19) AND SEM=S)  # не WON-копии при переходе в Sale
```

### MQL / Квал. лиды (карточка 2)
```
is_qual_lead:
  CAT_ID IN (0, 19)              # PreSale не входит
  И НЕ (SEM=S AND OPP < 11)      # не тех.нулевые
  
  Для Sale (0):
    И НЕ (SEM=S)                 # WON = уже оплачено, не MQL... хотя Ольга сказала WON считать как MQL
    И STAGE IN MQL_SALE_STAGES   # стадии MQL+
  
  Для КОМ (19):
    И НЕ (SEM=S)                 # WON-копии при переходе в Sale
    (всё остальное в КОМ = MQL)

Стадии ДО MQL (исключаются):
  NEW            — Исходный лид
  UC_1YW3V2      — Аларм/Распределение
  UC_STZB49      — Взят в работу
  UC_838R2R      — Консультирование

Стадии MQL+ (считаются):
  UC_4RJOR4 — MQL
  DETAILS   — SQL
  PROPOSAL  — Счёт отправлен
  2         — Постоплата
  6         — Частично оплачен
```
