  1. ⭐ UF_DATE_PAY_1C НЕ возвращается CRM Export API для сделок.
     Поле ЗАПОЛНЕНО на счетах (crm.invoice.UF_DATE_PAY_1C).

  2. CRM Export API НЕ возвращает STAGE_SEMANTIC_ID, CLOSED,
     PROBABILITY, SOURCE_ID, UTM-метки, 200+ UF-полей сделки,
     историю движения.

  3. CRM Export API возвращает УНИКАЛЬНЫЕ данные, которых нет в REST:
     - modules_ids (ID модулей курса внутри товара)
     - is_event (флаг мероприятия)
     - Обогащение: название компании, ФИО контакта, название формата,
       название направления, название категории
     - getFormats (7 форматов обучения)
     - getDirections (40+ направлений обучения)
     - getUserFieldsCrm (200+ UF-полей с описанием)

  4. Рекомендуемая архитектура:
     - REST API: выгрузка сделок + счетов (UF_DATE_PAY_1C, UTM, история)
     - REST API: каталог продуктов (crm.product)
     - Export API: обогащение + справочники (форматы, направления)
     - Export API: проверка UF-полей (через getUserFieldsCrm)

  5. Если export.php будет доработан:
     - Добавить в getDeals: UF_DATE_PAY_1C, STAGE_SEMANTIC_ID,
       UF_CRM_1683882427069, UF_CRM_1765896709800,
