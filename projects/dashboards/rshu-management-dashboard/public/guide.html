📊 Управленческий дашборд РШУ 2026

Инструкция для руководителей ·

Дашборд показывает ключевые показатели эффективности (KPI) по всем продажам Русской Школы Управления: поступления, воронка продаж, конверсия, разбивка по форматам, типам обучения, источникам и менеджерам.

🔧 Как пользоваться

Выбор периода

По умолчанию показываются данные с начала года по сегодня. Можно задать произвольный период:

  • 📅 Период — выберите даты начала и конца периода, за который смотреть метрики
  • 🔁 Сравнить с — выберите дату начала периода сравнения (по умолчанию — предыдущий период той же длины, вплотную к текущему)

Как работает сравнение: если вы выбрали период 01.01–30.06 (181 день), то период сравнения по умолчанию — предыдущие 181 день (03.07.2025–31.12.2025). Можно задать свою дату начала для кастомного сравнения.

Переключатели графика

Графики и таблица поддерживают два режима просмотра:

  • Недели — разбивка по неделям года
  • Месяцы — разбивка по месяцам

Переключение независимо для каждого блока: поступлений, воронки и недельной таблицы.

📈 Графики и диаграммы

Поступления по неделям/месяцам

Столбчатая диаграмма с накоплением. Показывает динамику поступлений отдельно по ООМ (голубой) и КОМ (фиолетовый) за каждую неделю/месяц. Наведите курсор на столбец — увидите сумму по каждому сегменту и итог.

Поступления по форматам

Пончик-диаграмма + таблица под ней. Показывает долю каждого формата в общей сумме поступлений:

  • Очный — очное обучение (ООМ)
  • Онлайн — онлайн-обучение (ОМ)
  • Дистанционный — СДО (видеокурсы)
  • Корпоративное обучение — КОМ

В таблице под диаграммой — сумма, количество сделок, средний чек и доля по каждому формату.

Поступления по типу обучения

Пончик-диаграмма + таблица. Показывает распределение поступлений по направлениям (Профессиональная переподготовка, Повышение квалификации, Семинары, MBA и т.д.).

Тип клиента: B2B / B2C

Пончик-диаграмма + таблица. Показывает долю B2B (компании) и B2C (частные лица) в поступлениях. В таблице — также данные предыдущего периода для сравнения.

Источники: Внутренняя база vs Маркетинговые сделки

Пончик-диаграмма + таблица. Показывает, сколько поступлений пришло из внутренней базы (сделки, созданные менеджерами напрямую) и из маркетинговых источников.

🔄 Воронка продаж

Стек-столбчатая диаграмма по неделям/месяцам. Каждый столбец показывает распределение лидов по стадиям:

  • Сделка — оплачено (закрыто успешно)
  • Счёт — на стадии выставления счёта
  • SQL — квалифицированный лид (согласовано обучение)
  • MQL — маркетинговый квалифицированный лид
  • Не квал. — не квалифицирован
  • Отказы — проигранные сделки

Наведите курсор на сегмент — увидите количество сделок, их долю и сумму (для SQL, Счёт и Сделка).

📋 Ключевые выводы

Блок автоматических выводов внизу страницы. Формируется на основе данных периода и последней полной недели:

  • 📊 В выбранном периоде — итоговые цифры: поступления, средний чек, медиана и взвешенный цикл, конверсия, соотношение B2B/B2C
  • 📈 Текущая неделя — данные последней полной недели с дельтой к предыдущей
  • 📥 Регистрация — ключевые метрики по каналу «Регистрация»
  • 🏆 Лидеры — лучший формат, источник и менеджер по сумме поступлений
  • 💡 Выводы — автоматические наблюдения (аномалии цикла, конверсии, падения недели)

❓ Частые вопросы

Почему данные не совпадают с участниками-дашбордом?

Управленческий дашборд считает все оплаченные сделки в выбранном периоде. Дашборд участников показывает только тех, кто учится в выбранную неделю. Разные выборки — разные цифры.

Как часто обновляются данные?

Данные обновляются вручную через загрузку из Bitrix24. Дата и время последней загрузки — в заголовке дашборда. Обычно — раз в день.

Что означает «Сравнить с»?

По умолчанию — предыдущий период той же длины. Например, если смотрите январь–июнь, сравнение будет с предыдущим полугодием. Можно задать свою дату начала периода сравнения.

Почему в поступлениях сумма больше, чем количество сделок × средний чек?

Поступления — это сумма оплаченных сделок. Средний чек — среднее по всем оплаченным сделкам. Если несколько сделок с разными чеками, произведение будет не точным (из-за округлений и весов).

Что такое «Оплаченные в периоде»?

Показывает, сколько процентов от суммы поступлений сформировано сделками, которые были созданы и оплачены в этом же периоде. Если значение низкое — сделки долго тянутся, многие приходят из предыдущих периодов.
