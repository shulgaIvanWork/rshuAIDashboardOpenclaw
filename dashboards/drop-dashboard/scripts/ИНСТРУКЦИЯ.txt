▌ ТРЕБОВАНИЯ
─────────────────────────────────────────────────────────────
• Python 3.9+
• pip install openpyxl          (для Excel-отчёта)
• Интернет-доступ к 24.uprav.ru (Битрикс24)

▌ СТРУКТУРА ФАЙЛОВ
─────────────────────────────────────────────────────────────
config.py        — ВСЕ настройки (URL, год, пути)
fetch_dicts.py   — справочники (воронки, пользователи, источники)
fetch_deals.py   — сделки из Битрикс24 (инкрементально)
fetch_leads.py   — лиды из Битрикс24 (инкрементально)
merge.py         — склеить страницы → deals_2026.json
analyze.py       — агрегация → agg.json
build_html.py    — сгенерировать HTML-дашборд
build_xlsx.py    — сгенерировать Excel-отчёт
run_full.py      — ПОЛНЫЙ запуск (первый раз / с нуля)
run_daily.py     — ЕЖЕДНЕВНОЕ обновление

▌ ПЕРВЫЙ ЗАПУСК (один раз)
─────────────────────────────────────────────────────────────
  cd /путь/к/папке/со/скриптами
  python run_full.py

  Это займёт 5–20 минут (зависит от объёма данных в Б24).
  Готовые файлы появятся в подпапке:  output/

▌ ЕЖЕДНЕВНОЕ ОБНОВЛЕНИЕ
─────────────────────────────────────────────────────────────
  python run_daily.py

  Подгружает только новые данные (быстро, ~1–3 мин).

▌ НАСТРОЙКА CRON (Linux/macOS)
─────────────────────────────────────────────────────────────
  Открыть crontab:  crontab -e
  Добавить строку (запуск каждый день в 07:00):

  0 7 * * * cd /путь/к/скриптам && python3 run_daily.py >> logs/daily.log 2>&1

▌ НАСТРОЙКА ПЛАНИРОВЩИКА ЗАДАЧ (Windows)
─────────────────────────────────────────────────────────────
  1. Открыть «Планировщик задач»
  2. Создать задачу → Триггер: ежедневно 07:00
  3. Действие: запустить программу
     Программа:   python.exe
     Аргументы:   run_daily.py
     Рабочая папка: C:\путь\к\скриптам

▌ КУДА ЗАГРУЖАТЬ НА СЕРВЕР
─────────────────────────────────────────────────────────────
  Папка для загрузки на веб-сервер:  output/
  В ней появятся:
    • Отчёт_продажи_2026.html  — открывается в браузере
    • Отчёт_продажи_2026.xlsx  — скачивается и открывается в Excel

  HTML-файл полностью самодостаточен (Chart.js подключается с CDN).
  Для работы без интернета замените в build_html.py строку:
    <script src="https://cdn.jsdelivr.net/...">
  на локальный файл chart.umd.min.js.

▌ ИЗМЕНИТЬ НАСТРОЙКИ
─────────────────────────────────────────────────────────────
  Все настройки — в файле config.py:
  • BASE      — URL вашего Битрикс24
  • YEAR      — отчётный год
  • OUTPUT_DIR — папка для готовых файлов

▌ ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
─────────────────────────────────────────────────────────────
  Начать с нуля:   python run_full.py
  Только один шаг: python fetch_deals.py --batches 1
  Посмотреть прогресс сделок: cat state_CREATE.json
  Посмотреть прогресс лидов:  cat leads_state.json
