# Инструкция: manager-report-dev

**URL:** https://uprav.tech/manager-report-dev/
**Путь:** `projects/dashboards/manager-report-dev/`
**Данные:** читает `agg.json` + `deals_NEW.json` из ratings-dashboard
**Коммит:** `cd1f6b3`

---

## Архитектура

`server.js` — Express-роутер. Загружает в память:
- `agg.json` (агрегированные KPI отдела)
- `deals_NEW.json` (все сделки 2025-2026, ~28к)
- `dicts.json` (справочники: пользователи, категории, источники)

При запросе с `?from=` и `?to=` — пересчитывает менеджеров за период в памяти (1 проход по deals).

**Ключевые фишки:**
- Фильтр по периоду (YTD / Янв-Июнь 2026)
- Группировка менеджеров (main/autopay/tech/bond/afanasyev/other)
- Горизонтальные stacked bar (без Chart.js, чистый CSS)

## Структура данных `GET /api/managers`

| Поле | Описание |
|---|---|
| `managers` | main + autopay + other + tech (для таблицы и баров) |
| `managersBond` | James Bond |
| `managersAfanasyev` | Дмитрий Афанасьев |
| `managersTech` | Технические (ОЗК/КОМ отдел) |
| `weeks` | Понедельная воронка отдела |
| `ytd` | KPI всего отдела |
| `period` | Текущий период (YTD или даты) |

## Параметры запроса

```
GET /api/managers                          — YTD
GET /api/managers?from=2026-04-01&to=2026-04-30  — Апрель 2026
```

## Правила расчёта

| Поле | Условие | OPP≥11? |
|---|---|---|
| in_work_start | DC ≤ cutoff, PAY_DT пусто, SEM≠F, кат 0/19 | ❌ |
| created | DC в периоде, кат 0/8/19 | ❌ |
| paid | PAY_DT в периоде, кат 0/8/19 | **✅ да** |
| lost | SEM=F, кат 0/8/19 | ❌ |
| mql | is_qual_lead_w по DC, кат 0/8/19 | ❌ |
| sql | стадии SQL+ по DC | ❌ |
| invoice | UF_CRM_1753272713011 («Дата Счет отправлен») | ❌ |
| avg_dur | (PAY_DT - DC).days для оплаченных | — |

## Срезы (горизонтальные stacked bar)

1. **B2B/B2C** — по COMPANY_ID (есть компания → B2B, нет → B2C)
2. **Источники** — внутренняя база vs маркетинг (по SOURCE_ID)
3. **Форматы** — ООМ (19042467), ОМ (19042468), СДО (19042469)

## Логика MQL (`is_qual_lead_w`)

| Категория | Условие |
|---|---|
| Sale (0) | Не NEW, Аларм, Взят, Консульт |
| PreSale (8) | ❌ не входит |
| КОМ (19) | ✅ всё кроме WON и LOSE |

| Условие | Действие |
