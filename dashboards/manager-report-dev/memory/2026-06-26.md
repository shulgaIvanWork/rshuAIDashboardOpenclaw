## Новая последовательная воронка (вместо независимых счётчиков)
### Этапы (каждый следующий — подмножество предыдущего):
1. **Создано** — все сделки в периоде (созданные + переходящие), без дублей WON КОМ/PreSale
2. **На квалификации** — PreSale (кроме WON/LOSE) + Sale (NEW, UC_1YW3V2, UC_STZB49, UC_838R2R)
3. **MQL** — ранг ≥4 (UC_4RJOR4+), включая ушедших в отказ после
4. **SQL** — ранг ≥5 (DETAILS+), включая ушедших в отказ после
5. **Счёт** — ранг ≥6 (PROPOSAL+) + дата счёта, включая ушедших в отказ после
6. **Оплачено** — UF_DATE_PAY_1C + OPP≥11
7. **Квал отказы** — LOSE при ранге ≥4 или КОМ (кат 19)
8. **Не квал отказы** — LOSE при ранге <4 (PreSale/Sale квалификация)
