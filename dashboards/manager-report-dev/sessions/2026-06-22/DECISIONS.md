## Утверждённые правила расчёта

### 1. in_work_start
- `DATE_CREATE ≤ cutoff`
- `UF_DATE_PAY_1C` пусто
- `STAGE_SEMANTIC_ID ≠ F`
- Категория 0 (Sale) или 19 (КОМ)
- OPPORTUNITY — не проверяем

### 2. Paid (оплачено)
- Единственное правило с `OPPORTUNITY ≥ 11`
- Есть `UF_DATE_PAY_1C`

### 3. Lost (проиграно)
- `STAGE_SEMANTIC_ID = F`
- CLOSEDATE не используется
- OPPORTUNITY не проверяем

### 4. Created (создано)
- `DATE_CREATE` в периоде
- Категория 0/8/19
- OPPORTUNITY не проверяем
