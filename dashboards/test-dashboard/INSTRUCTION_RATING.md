# Инструкция: Рейтинг продуктов (май 2026+)

## 1. Источники данных

### Основной: выгрузка из Bitrix24 (Excel/HTML)
Это выгрузка оплаченных сделок через интерфейс Bitrix24.
Содержит все нужные поля текстом (не ID).

**Как получить:**
1. Bitrix24 → Сделки → Экспорт/Отчёт по сделкам
2. Фильтр: воронка Sale, статус WON, дата оплаты из 1С = май (или нужный месяц)
3. Выгрузить в Excel

Файл подкладывается в: `/root/.openclaw/media/inbound/`

### Дополнительно: API Bitrix24 (crm.item)
Используется для верификации.
- Метод: `crm.item.list` (entityTypeId=2) и `crm.item.get`
- В отличие от `crm.deal.list`, показывает UF-поля с корректными названиями

## 2. Поля Bitrix24 (соответствие)

| Выгрузка (интерфейс) | API (crm.item) |
|---|---|
| ID сделки | id |
| Название сделки | title |
| Сумма | opportunity |
| Дата оплаты из 1С | ufDATE_PAY_1C |
| Формат | ufFormat (ID инфоблока) |
| Направление обучения | ufCrm_1744273716729 |
| Тип обучения | ufCrm_1498466811 |
| Есть в Аккаунтинге | — |
| Тип (ДРОП) | typeId |

## 3. Фильтры

Отбираются только сделки:
- Воронка **Sale** (categoryId=0)
- Статус **Счет оплачен** (WON, stageSemanticId=S)
- **Дата оплаты из 1С** за нужный месяц (ufDATE_PAY_1C)
- Сумма > 0 (не технические)

## 4. Исключения

Из основного рейтинга исключаются:
1. **Корпоративное обучение** — направление обучения = "Корпоративное обучение"
2. **ILP программы** — название сделки начинается с "ILP" или содержит " ILP "

ILP и Корп.обучение выводятся отдельным блоком (опционально).

## 5. Очистка названий продуктов

Регулярные выражения (JS-синтаксис):
```
1. "НЕ удалять пока! " → удалить
2. Даты: \d{2}\.\d{2}\.\d{4}, \d{4}-\d{2}-\d{2} → удалить
3. "с ..." / "по ..." → удалить
4. Города: "в г.Москва", "(Москва)", "(Санкт-Петербург)" → удалить
5. Форматы в скобках: "(СДО)", "(онлайн)" → удалить
6. Договоры: "Договор № 12345 от 01.01.2024" → удалить
7. Остатки дат: "13.04-", "06" в конце → удалить
8. Лишние пробелы → схлопнуть
```

## 6. Группировка

Сгруппировать по очищенному названию → суммировать:
- Кол-во продаж
- Выручка
- Разбивка по форматам (СДО / очный / онлайн)

## 7. Сортировка

- ТОП по сумме: по выручке (убыв.)
- ТОП по количеству: по кол-ву (убыв.), при равенстве по выручке

## 9. Запуск скрипта вручную (если файл выгрузки обновлён)

Скрипт не требуется — дашборд сам читает файл через API.
При обновлении файла достаточно перезапустить web-interface:
```
pm2 restart clover-web
```

## 11. Возможные проблемы

1. **Файл не найден** — проверь путь `/root/.openclaw/media/inbound/выгрузка_май_2026---*.xls`
2. **Битая кодировка** — файл должен быть UTF-8 (с BOM)
3. **Нет данных** — проверь, что файл существует и читается
4. **Пустые значения** — если в выгрузке нет новых оплат
