## 1. Стек 1 — Воронка продаж (активные сделки)

### Что показывает
Загрузку менеджеров: сколько сделок активно на каждой неделе.

### Высота столбца
Все сделки, которые:
- CAT_ID IN (0, 8, 19)
- DATE_CREATE ≤ sun недели
- НЕ оплачены до mon (UF_DATE_PAY_1C < mon → excluded)
- НЕ проиграны до mon (SEM=F + CLOSEDATE < mon + CLOSED=Y → excluded)
- НЕ формально закрыты до mon (CLOSED=Y + CLOSEDATE < mon → excluded)
- НЕ тех.нулевые WON (WON + OPP<11)
- НЕ WON-копии C8:WON

**Ожидаемая высота:** ~1.4-1.5k

## 3. KPI — 3 строки × 7 карточек

### 3.1. Деление ООМ/КОМ
**5 признаков КОМ (any of):**
1. UF_CRM_1683882427069 = Y (галочка КОМ)
2. UF_FORMAT = 19042498 (КОМ)
3. UF_CRM_1498466811 содержит 1906 (Корп. обучение)
4. CATEGORY_ID = 19
5. UF_CRM_1765896709800 = 34765 (КОМ)

**Исключение:** одна сделка не может быть одновременно ООМ и КОМ (непересекающиеся множества).

### 3.2. Поступления (карточка 1)
UF_DATE_PAY_1C есть + OPP ≥ 11 + CAT IN (0,8,19)
SEM не проверяется (любая стадия)

### 3.3. Лиды и MQL (карточка 2)

**is_all_lead:** CAT IN (0,8,19) + не тех.нулевые WON (OPP<11) + не WON-копии в 8|19

**is_qual_lead (MQL):**
- Sale: стадии MQL+ (все, кроме NEW/Аларм/Взят/Консульт, включая WON)
- КОМ: все кроме WON (S) и LOSE (F)
- PreSale (8): НЕ входит в MQL

### 3.4. Срок WON
Дни от DATE_CREATE до UF_DATE_PAY_1C
Только дни ≥ 0 (отрицательные — в артефакты)

## 5. Ограничения

- MIN_OPP = 11.0 ₽ (сделки 0-10 нигде не учитываются)
- VALID_CATS = {0, 8, 19}
- Export API не возвращает UF_* поля → fetch_kom_enrich.py
- Расчёт YTD: с 1 января по сегодня
- Недели: ISO-недели (isocalendar)
