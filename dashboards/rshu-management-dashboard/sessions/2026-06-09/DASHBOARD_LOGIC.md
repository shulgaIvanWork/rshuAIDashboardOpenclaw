## Лиды сейл — правильный расчёт (от Ольги 28.05.2026)

**Лид сейл** = сделки в воронке **Sale** («Общая (по умолчанию)»).
- Исключать **технические сделки**: статус «счёт оплачен», сумма=0 (нулевые оплаченные). Их НЕ считаем нигде и никогда.
- Все счета и оплаты — **ТОЛЬКО по воронке Sale**. Не Отказы, не Pre Sale, не КОМ.

**MQL, SQL** = просто стадии воронки **Sale** (не отдельные категории!).
- Не путать с Pre Sale категорией — это другое.

**Когда просят «все лиды за период»**:
1. Лиды сейл (сделки в Sale воронке, без нулевых тех.)
2. + Pre Sale: **рабочие стадии** (в работе) + **закрытые** (все, включая проигранные)
   - НЕ добавлять **успешные** (WON) стадии Pre Sale — это копии для статистики
3. + КОМ (Sale): **рабочие стадии** + **закрытые** (все, включая проигранные)
   - НЕ добавлять **успешные** (WON) стадии КОМ — это копии для статистики

**Технические (нулевые) сделки**: статус «счёт оплачен», OPPORTUNITY=0 → исключать всегда.

**Стадии воронки Sale (Общая по умолчанию):**
- PROPOSAL → 2 → 6 → WON (оплачено)
- «Счёт отправлен» = стадия **6** (предоплата/закрытие)
- Коэффициент конверсии 6→WON = ~80-90% (продвинутая стадия)
- Коэффициент конверсии пайплайн→WON = ~57.6% (WON/(WON+LOSE) по Sale)

## Стадии воронки Sale (Общая по умолчанию) — уточнение
Все счета и оплаты — ТОЛЬКО по воронке Sale. Не Отказы, не Pre Sale, не КОМ.
Стадии в работе (P) с суммой > 0: PROPOSAL → 2 → 6 (счёт отправлен) → WON
«Счёт отправлен» = стадия 6. Коэф. 6→WON ≈ 80% (последняя стадия перед оплатой).

## Артефакты оплат (правило для всех дашбордов)

При поиске оплаченных сделок по `UF_DATE_PAY_1C` (дата оплаты из 1С):
- **Основной рейтинг:** берём сделки со статусом **S (WON/успех)** — штатно оплаченные и закрытые
- **Артефакты (выводить отдельно с пометкой «*»):**
  - **P (в работе)** + есть UF_DATE_PAY_1C → частичная оплата, рассрочка (деньги есть, сделка не закрыта)
  - **F (проиграно)** + есть UF_DATE_PAY_1C → возврат клиенту (деньги вернули, сделка проиграна)

Артефакты не исключаются, а выводятся в конце отчёта отдельным блоком со звездочкой.
