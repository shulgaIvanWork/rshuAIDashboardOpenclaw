Предложение по структуре и сборке ·

1. Концепция

Объединить три существующих дашборда в один универсальный отчёт для отдела продаж. Базовый слой — логика управленческого дашборда (воронка, KPI, конверсии). Дополнения — конвейер переходящих сделок, детализация по дням/неделям/месяцам и полноценный разрез по менеджерам.

Ключевое: менеджеры видят свой собственный срез. Месяц — основной горизонт планирования. Сравнение с прошлым периодом — второстепенно, главное — движение внутри текущего месяца.

4. База для сборки

Предлагаю создать новый дашборд — sales-report-dashboard — отдельное под-приложение npm workspaces.

Почему новый, а не доработка существующего:

  • Управленческий дашборд — стабилен, менять его рискованно
  • Рейтинги — уже переработаны, не трогать
  • Новый дашборд = новый server.js + app.js, без конфликтов с текущими
  • Данные — единые из getAgg(), менеджерская логика — в своём server.js
  • К моменту готовности старые дашборды можно выключить

Структура нового дашборда:

dashboards/sales-report-dashboard/
├── server.js           # API + менеджерская аналитика
├── package.json
└── public/
    ├── index.html       # 4 вкладки
    ├── app.js           # фронт
    └── styles.css
