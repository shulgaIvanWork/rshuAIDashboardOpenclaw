📊 Рейтинги 2026 — инструкция

Адрес: uprav.tech/ratings-dashboard/ · Данные: Bitrix24 (data-service) · Отчётный год: 2026

1. Быстрый старт

  • 📅 Период — выберите диапазон дат (календарь, режим «Range»). По умолчанию — с 01.01.2026 по сегодняшний день.
  • Все таблицы пересчитываются под выбранный период; у карточек — дельты к сравнению.
  • Обновление данных — данные забираются из Bitrix24 централизованно в data-service (npm run fetch); кэш дашбордов обновляется автоматически. Актуальность показана в заголовке («Данные на: …»).

Дашборд состоит из двух вкладок: «Рейтинги» (основная) и «Лиды по направлениям». Верхний фильтр периода — общий для обеих вкладок.

2. Выгрузка в Excel

  • На вкладке «Рейтинги» кнопка «📥 Скачать Excel» (вверху) выгружает 4 листа:
    • Продукты
    • Источники
    • Компании
    • Семейство МВА
  • На вкладке «Лиды по направлениям» своя кнопка «📥 Выгрузить» — выгружает только таблицу сделок с учётом выбранных фильтров (направление и группа стадий).

3. Вкладка «Рейтинги»

3.1. Продукты (ТОП-20)

  • Топ-20 продуктов по поступлениям за период (без КОМ и конструктора ILP). Есть фильтр по направлению.
  • Клик по заголовку — сортировка. Итоговая строка — «📦 Остальные» + «Остальные».

3.2. Рейтинг источников

  • Источники с полной воронкой: Лиды → MQL → SQL → Счёт → Сделки → Поступления, конверсии и тип трафика (ВНБ / МТ).

3.3. Топ-20 компаний

  • Компании по поступлениям, число сделок ОМ / КОМ, средний чек, доля, последняя оплата.

3.4. Семейство МВА

  • Разбивка по продуктам семейства МВА / Mini-MBA.

4. Вкладка «Лиды по направлениям» (новая)

Показывает, сколько лидов заведено по каждому направлению за период и сколько из них оплачено — то есть качество направлений, а не только состоявшиеся продажи. Состоит из двух таблиц под общим фильтром периода.

Что считается

  • База — сделки, созданные в выбранном периоде (по дате создания), воронки Sale + Pre Sale. КОМ не берётся.
  • Направление определяется по приоритету:
    1. из товара (направление курса) — основной источник;
    2. если пусто — «Направление при создании» (текст с сайта/форм). Значения из анкеты сведены к справочнику направлений («Право» → «Корпоративное право», «Персонал» → «Управление персоналом» и т.д.).
  • Каждая сделка учитывается один раз (в одном направлении).
  • Оплачено — есть дата оплаты из 1С (включая частично оплаченные), как во всех остальных отчётах.

4.1. Таблица 1 — сводка по направлениям

КолонкаЧто значит
НаправлениеНаправление обучения (каноническое название из справочника)
Заведено, штВсе сделки, созданные за период по этому направлению
Добавлено при работе продаж, штСколько сделок получили направление из товара (т.е. в ходе работы)
Оплачено, штИз заведённых — оплаченные (есть дата оплаты 1С)
Сумма, ₽Сумма оплаченных сделок

Клик по заголовку — сортировка. Строка «Без направления» — сделки, где направление не заполнено ни в товаре, ни при создании.

4.2. Таблица 2 — список сделок

Под сводкой — список самих сделок с фильтрами:

  • Направление — «Все направления» или конкретное.
  • Стадии — группы:
    • Оплачено — есть дата оплаты 1С (вкл. частичные);
    • Отказ — стадии «Предзакрытие в отказ» и «Закрыто и не реализовано»;
    • В работе — все остальные (проверка по порядку: оплата → отказ → в работе).
  • Кнопка «📥 Выгрузить» — Excel только по этой таблице (с учётом фильтров).

4.3. Артефакты

Внизу вкладки — блок «⚠️ Артефакты»: исключённые значения («blog» и подобный мусор), нераспознанный текст направления, сделки без направления и отказные без указанной причины. Это подсказка, где данные заполнены некорректно.

Правила расчёта направлений и список соответствий ведутся в data-service/lib/direction-map.js; при появлении новых названий направления в анкете их нужно добавить в справочник.

5. Печать / PDF

  • Любую вкладку можно распечатать или сохранить в PDF: Ctrl+P (Cmd+P), формат A4.
  • Быстрая выгрузка данных — кнопками «Скачать Excel» (рейтинги) и «Выгрузить» (лиды по направлениям).
Дата обновления данных — метка времени в заголовке дашборда; актуализация — централизованной выгрузкой data-service (npm run fetch).
